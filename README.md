## 📖 Overview

**Hakim** is a comprehensive healthcare mobile application developed using **Flutter** as a Graduation Project. It is designed to simplify clinic operations by providing doctors and assistants with an intelligent platform for managing appointments, patient records, prescriptions, and medical reports.

The application integrates **Artificial Intelligence** to assist doctors with speech-to-text medical documentation, laboratory report interpretation, medical image analysis, and clinical decision support, helping improve efficiency while reducing administrative workload.

# 🏗️ System Architecture

The application follows the **MVVM (Model–View–ViewModel)** architecture to ensure maintainability, scalability, and separation of concerns.

```
Presentation Layer
       │
       ▼
ViewModel
       │
       ▼
Repository
       │
       ▼
REST API (Dio)
       │
       ▼
Backend Server
```
